# 06: Gestionar Owned copies manualmente

**Parent:** [MVP del asistente de colección Riftbound](../../riftbound-mvp-spec/SPEC.md)

**What to build:** Permitir que cada Beta tester mantenga manualmente su Collection como ejemplares físicos individuales y vea cantidades derivadas, sin exponer ni afectar a otro tester.

**Blocked by:** 04: Aplicar ciclo de cuenta y aislamiento; 05: Explorar Cards y Printings.

**Status:** ready-for-agent

- [ ] Cada tester obtiene una única Collection privada y solo puede operar sus propias Owned copies.
- [ ] Se pueden añadir una o varias Owned copies desde una Card o Printing seleccionada.
- [ ] Cada copia conserva Printing, idioma, acabado, condición y nota opcional.
- [ ] Se puede editar o eliminar una copia concreta y ajustar por lote copias equivalentes.
- [ ] Las cantidades mostradas se derivan contando Owned copies y no dependen de un contador agregado editable.
- [ ] La vista visual permite buscar, filtrar y reconocer Cards/Printings en escritorio y móvil.
- [ ] Tests de integración y navegador cubren CRUD, lotes, cantidades derivadas y aislamiento.
