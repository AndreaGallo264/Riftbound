# 01: Confirmar derechos de datos para producción

**Parent:** [MVP del asistente de colección Riftbound](../../riftbound-mvp-spec/SPEC.md)

**What to build:** Obtener y registrar una base verificable para usar datos y contenidos de Riftbound en producción, para que una fuente pública o un script open source no se confundan con una licencia sobre los datos de Riot.

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [ ] Se documenta que la licencia MIT de `slimtreble/Riftbound-card-data` cubre solo sus scripts y excluye datos, texto y arte de Riot.
- [ ] El dataset comunitario se limita a fixtures locales de prototipo y no se despliega como fuente de producción mientras este ticket siga abierto.
- [ ] Una licencia o autorización verificable confirma qué fuente puede alimentar el Card catalog de producción y con qué retención/atribución.
- [ ] La misma verificación cubre o rechaza snapshots, extracción, fragmentos, embeddings y RAG sobre reglas y otros documentos oficiales.
- [ ] Se confirma el alcance permitido para decklists y evidencia competitiva, incluida la prohibición de agregados de Metagame.
- [ ] La evidencia de la respuesta, sus condiciones y su fecha queda accesible para los dos desarrolladores sin incluir secretos en el repositorio.
- [ ] Cualquier uso rechazado o no contestado queda documentado como no autorizado para los tickets dependientes.
